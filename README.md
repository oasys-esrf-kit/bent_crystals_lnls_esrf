# bent_crystals_lnls_esrf

Ray-tracing simulations of sagittally focusing bent-crystal monochromators (bent Laue and
Bragg–Laue), using [xrt](https://github.com/kklmn/xrt) 2.0 and
[OASYS2-XRT](https://github.com/oasys-esrf-kit/OASYS2-XRT).

Four beamlines are simulated:

| Beamline | Source | Monochromator | Energies |
|---|---|---|---|
| APS_BLM | 7 GeV bending magnet | Si(311) Bragg (Johann) + bent Laue | 30–60 keV |
| SSU_BLM | 3 GeV bending magnet, 6.6 T | Si(311) Bragg (Johann) + bent Laue | 35–200 keV |
| SSU_SBDL | 3 GeV bending magnet, 6.6 T | two bent Si(111) Laue crystals (PP) | 35–200 keV |
| BNL_SBDL | 3 GeV wiggler | two bent Si(111) Laue crystals (ML) + Pt mirror | 30–70 keV |

## Where to start

- **[XRTcodes/RUN_XRT.md](XRTcodes/RUN_XRT.md):** how the scripts were run, what they
  compute, the main results with full per-energy tables, how the bent-crystal model works,
  and the comparison of the internal Laue reflectivity with XOPPY.
- **OASYS2 workspaces**, one per beamline at a single energy. Each folder has the `.ows`
  workspace, the Python script generated by the XRT Runner widget, and an `INFO.md` with
  the settings, results and differences from the original script:
  - [XRTcodes/oasys_APS_BLM](XRTcodes/oasys_APS_BLM/INFO.md): APS_BLM at 44 keV
  - [XRTcodes/oasys_SSU_BLM](XRTcodes/oasys_SSU_BLM/INFO.md): SSU_BLM at 80 keV
  - [XRTcodes/oasys_SSU_SBDL](XRTcodes/oasys_SSU_SBDL/INFO.md): SSU_SBDL at 50 keV
  - [XRTcodes/oasys_BNL_SBDL](XRTcodes/oasys_BNL_SBDL/INFO.md): BNL_SBDL at 40 keV

## Known issues

Both issues are **fixed in the code**, and the scans have been rerun
(`XRTcodes/run_XRT_*_fixed/`). [XRTcodes/RUN_XRT.md](XRTcodes/RUN_XRT.md) shows the new
results, keeps the old ones (`XRTcodes/run_XRT_*/`) for reference, and has a TODO list of
the decisions still pending for the Bragg+Laue beamlines.
[XRTcodes/RERUN_RESULTS.md](XRTcodes/RERUN_RESULTS.md) compares old and new results energy
by energy. The OASYS workspaces were rerun with the fixed code; their `INFO.md` files show
the new and the old results.

- **[XRTcodes/BUG_ML.md](XRTcodes/BUG_ML.md):** the internal multilamellar (ML)
  reflectivity had three bugs, now fixed and checked against XOPPY.
  - Laue was too high: about 1.4× XOPPY in the SSU_BLM case.
  - Bragg ignored absorption.
  - Open question: which absorption coefficient to use. xrt's total value is the current
    choice; XOPPY uses photoelectric only.
- **[XRTcodes/BUG_GEOMETRY.md](XRTcodes/BUG_GEOMETRY.md):** the scripts passed the local
  beam of the 10 m mask downstream. This effectively moved the optics 10 m farther from the
  source and explains the Fcurv values above 1. The OASYS workspaces always used the
  correct geometry.

## Contents of XRTcodes/

| Path | Content |
|---|---|
| `XRT_*.py` | Energy-scan scripts for the four beamlines (`XRT_SSU_BLM_PP.py`: SSU_BLM with PP Laue reflectivity) |
| `BentCrys2D.py` | Bent crystal optical element and `bentSi_Crys` reflectivity (PP and ML), adapted to xrt 2.0 |
| `stiffness_tensor.py` | Elastic constants of Si rotated to the crystal axes |
| `geometry_correction.py` | Fcurv optimization used by the scripts |
| `oes_base.py` | Patched xrt 1.x `oes_base.py` (not needed with xrt 2.0) |
| `plot_*.py` | Plotting scripts for the results |
| `run_XRT_*/` | Results of the full runs: `res_*_energy.txt`, logs, images |
| `XOPPY/` | Comparison of the internal Laue reflectivity with XOPPY `diff_pat` |
| `oasys_*/` | OASYS2-XRT workspaces (see above) |

## Requirements

- Python with `xrt` 2.0, `numpy` and `matplotlib` to run the scripts.
- OASYS2 with OASYS2-XRT for the workspaces. They need the Bending Magnet, Wiggler,
  Johann Cylinder Crystal and Bent Crystal 2D widgets.
- `xoppylib` and `dabax` for the XOPPY comparison scripts.
